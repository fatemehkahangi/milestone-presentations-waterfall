# STC Time Management System - User Handbook

## Scenario: Submitting and Approving a Monthly Timesheet

### Step 1: Employee Submission
1. Log into the system using your employee credentials (e.g., `alex@stc.de` / `test123`) And check the time-flex balance.
2. Navigate to the **Timesheet** view from the side menu.
3. Use the date selector to choose the desired month.
4. Add a few entries.
5. Click the **"Submit time sheet"** button. The sheet will be locked against further edits. Log out

### Step 2: Supervisor Approval
1. Log into the system as a supervisor (e.g., `ingrid@stc.de` / `test123`) and navigate to the **Approvals** view.
2. Click **"Review"** to inspect individual time entries.
3. Click **"Approve"** to accept the timesheet. Log out

### Step 3: Employee Results
1. Log into the system using your employee credentials (e.g., `alex@stc.de` / `test123`).
2. Check the updated flex-time balance 
3. Navigate to the **Timesheet** view from the side menu.
4. Use the date selector to choose the desired month.
5. Check the status of timesheet
