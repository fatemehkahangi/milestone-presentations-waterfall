# STC Time Management System

## Project Overview

STC is a small technology company specializing in mechanical
engineering. Currently, employees use individual Excel files
to record their working hours.

The goal of this project is to develop a centralized time
management system for recording working hours, managing
vacation requests, registering sickness, and tracking flex-time
and vacation balances.

The system will support employees, supervisors, and HR.

## Project Methodology

This project follows the Waterfall (plan-driven) development
approach.

## Project Phases

1. Customer Interview
2. Requirements Specification
3. Design
4. Implementation
5. Testing

## Repository Structure

- `01-requirements-specification/`: Requirements and diagrams
- `02-design/`: System design
- `03-implementation/`: Implementation
- `04-testing/`: Test plans and test results
- `05-final-documentation/`: Final project documentation
